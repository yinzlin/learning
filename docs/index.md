## 学习计划概览

本学习计划基于 Rust 1.90.0（2025-09-18）和 Rust 2024 Edition 的官方文档，旨在帮助学习者系统掌握 Rust 语言从基础到高级的所有核心概念和特性。

### 学习目标
- 掌握 Rust 语言的基本语法和核心概念
- 理解 Rust 独特的所有权系统
- 能够使用 Rust 构建各种类型的应用程序
- 掌握 Rust 的高级特性和最佳实践

### 学习时间
- 总时长：约 18 周
- 每周投入：10-15 小时

### 学习方法
- 理论学习与实践相结合
- 循序渐进，按阶段学习
- 利用官方文档和社区资源
- 构建实际项目巩固所学知识

## 开始学习

从 [步骤 1：环境搭建](step01-环境搭建.md) 开始，按照顺序逐步完成每个步骤的学习内容。
