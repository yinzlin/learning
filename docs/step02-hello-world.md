# 步骤 2：Hello World 实践

## 操作目标
编写并运行第一个 Rust 程序，熟悉 Rust 的基本编译和运行流程。

## 执行方法

### 1. 创建源文件

1. 打开文本编辑器
2. 创建一个名为 `main.rs` 的文件
3. 输入以下代码：
   ```rust
   fn main() {
       println!("Hello, world!");
   }
   ```

### 2. 编译程序

1. 打开终端
2. 导航到 `main.rs` 文件所在的目录
3. 执行以下命令编译程序：
   ```bash
   rustc main.rs
   ```

### 3. 运行程序

#### Linux/macOS
执行以下命令：
```bash
./main
```

#### Windows
执行以下命令：
```bash
.ain.exe
```

### 4. 查看输出

运行程序后，终端将显示：
```
Hello, world!
```

## 所需资源
- 文本编辑器（如 VS Code、Sublime Text 等）
- 终端
- Rust 开发环境（已在步骤 1 中安装）

## 时间节点
- **开始时间**：学习计划第 1 天
- **完成时间**：学习计划第 1 天

## 预期成果
- 成功编写第一个 Rust 程序
- 能够编译 Rust 源代码
- 能够运行编译后的可执行文件
- 看到 "Hello, world!" 输出

## 优先级
- **优先级**：高
- **理由**：Hello World 是学习任何编程语言的第一步，帮助建立基本的编程环境和流程认识

## 风险点与应对措施

| 风险点 | 应对措施 |
|-------|--------|
| 编译错误 | 检查代码是否正确，确保语法无误 |
| 运行错误 | 检查文件路径和命令是否正确 |
| 权限问题 | 确保有执行文件的权限 |

## 验证步骤

1. 确认 `main.rs` 文件已创建并包含正确的代码
2. 执行 `rustc main.rs` 编译程序
3. 执行编译后的可执行文件
4. 确认终端显示 "Hello, world!"
