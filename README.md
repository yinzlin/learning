# Rust 编程语言知识体系完整示例代码

本项目包含系统化的 Rust 编程语言示例代码，全面覆盖 Rust 核心知识点、语法特性和最佳实践。

## 项目结构

```
src/
├── main.rs              # 主程序入口
├── basics.rs            # 基础概念：变量、数据类型、函数、控制流
├── ownership.rs         # 所有权系统：所有权、引用、切片
├── data_structures.rs   # 数据结构：结构体、枚举、集合类型
├── error_handling.rs    # 错误处理：panic、Result、自定义错误
├── generics_traits.rs   # 泛型与特性：泛型、trait、生命周期
├── functional.rs        # 函数式编程：闭包、迭代器
├── smart_pointers.rs    # 智能指针：Box、Rc、RefCell、Drop
├── concurrency.rs       # 并发编程：线程、消息传递、共享状态
└── advanced.rs          # 高级特性：unsafe、高级类型、宏、模式匹配
```

## 知识点覆盖

### 模块一：基础概念
- 变量与可变性（不可变变量、可变变量、常量、隐藏）
- 数据类型（标量类型、复合类型）
- 函数（定义、参数、返回值）
- 控制流（if、loop、while、for）
- 注释（单行、多行、文档注释）

### 模块二：所有权系统
- 所有权概念（所有权转移、复制语义、克隆语义）
- 引用与借用（不可变引用、可变引用、借用规则）
- 切片类型（字符串切片、数组切片）

### 模块三：数据结构
- 结构体（定义、实例化、方法、关联函数）
- 枚举（定义、Option、match、if let）
- 集合类型（Vector、String、HashMap）

### 模块四：错误处理
- 不可恢复错误（panic!）
- 可恢复错误（Result、? 操作符）
- 错误处理策略（自定义错误类型）

### 模块五：泛型与特性
- 泛型数据类型（泛型函数、泛型结构体）
- 特性（定义、实现、trait bound）
- 生命周期（生命周期标注、省略规则）

### 模块六：函数式编程
- 闭包（定义、捕获环境、Fn traits）
- 迭代器（Iterator trait、消费适配器、迭代器适配器）

### 模块七：智能指针
- Box<T>（堆分配、递归类型）
- Drop 特性（自定义析构）
- Rc<T>（引用计数）
- RefCell<T>（内部可变性）

### 模块八：并发编程
- 线程（创建、join、move 闭包）
- 消息传递（channel、多发送者）
- 共享状态（Mutex、Arc）
- 同步原语（原子类型、Barrier、Once）

### 模块九：高级特性
- 不安全 Rust（原始指针、unsafe 函数、静态变量）
- 高级类型（新类型模式、类型别名、Never type、DST）
- 高级函数和闭包（函数指针、返回闭包）
- 宏（声明式宏、过程宏概念）
- 高级模式匹配（匹配守卫、绑定模式、解构）

## 运行方式

```bash
# 检查代码
cargo check

# 运行程序
cargo run

# 构建发布版本
cargo build --release
```

## 学习建议

1. **按顺序学习**：从基础概念开始，逐步深入高级特性
2. **动手实践**：修改示例代码，观察编译器和运行结果
3. **阅读文档**：结合 Rust 官方文档深入理解
4. **编写测试**：为示例代码编写单元测试
5. **实际项目**：将学到的知识应用到实际项目中
