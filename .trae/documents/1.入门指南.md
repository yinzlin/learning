# 第 1 章 入门指南

## 1.1 安装 Rust

使用 `rustup` 工具安装 Rust，这是 Rust 官方推荐的版本管理工具。

### Linux/macOS

```bash
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

### Windows

访问 [Rust 官网](https://www.rust-lang.org) 下载安装程序，按提示完成安装。

> **注意**: Windows 系统可能需要安装 Visual Studio 提供的链接器。

### 验证安装

```bash
rustc --version
```

## 1.2 更新 Rust

使用以下命令将 Rust 升级到最新稳定版本：

```bash
rustup update
```

## 1.3 查看本地文档

安装 Rust 时会自动附带本地文档，通过以下命令可在浏览器中打开离线文档：

```bash
rustup doc --book
```

方便查阅标准库 API 等内容。

## 1.4 Hello, World!

### 使用 rustc 直接编译

1. 创建 `main.rs` 文件：

```rust
fn main() {
    println!("Hello, world!");
}
```

2. 编译程序：

```bash
rustc main.rs
```

3. 运行程序：

- Linux/macOS: `./main`
- Windows: `.\main.exe`

## 1.5 使用 Cargo

### 创建新项目

```bash
cargo new project_name
```

Cargo 会自动生成项目目录结构，包括：
- `src/main.rs` - 主程序文件
- `Cargo.toml` - 项目配置文件

### 常用命令

| 命令 | 说明 |
|------|------|
| `cargo build` | 编译项目 |
| `cargo run` | 编译并运行程序 |
| `cargo check` | 快速检查代码是否可编译（不生成可执行文件） |
| `cargo build --release` | 以发布模式编译（优化编译） |
